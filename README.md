Overview

REOYH is a frontend-based web platform designed to connect students with tutors and educational opportunities through a clean, structured, and user-friendly interface.

The goal of this project is to simulate a real-world education platform where users can explore tutors, access dashboards, and interact with different sections of the system.

Problem Statement

Students often struggle to find reliable tutors or relevant academic opportunities in a structured way.

REOYH aims to solve this by:

Providing a centralized platform for tutor discovery
Offering role-based dashboards (student and tutor)
Creating an organized and scalable frontend structure
