# REOYH – Tutor Booking Platform

REOYH is a web-based platform that connects students with tutors for personalized learning.

## Features

* User Authentication (Firebase)
* Become a Tutor
* Find Tutors with Filters
* Tutor Profile Page
* Book Sessions
* Student Dashboard with Booking History

## Tech Stack

* HTML, CSS, JavaScript
* Firebase Authentication
* Firebase Firestore

## How It Works

1. User signs up or logs in
2. Tutors register themselves
3. Students search tutors using filters
4. View tutor profile
5. Book a session
6. View bookings on dashboard

## Folder Structure

* `/pages` → HTML pages
* `/js` → JavaScript logic
* `/css` → Styling
* `/assets` → Images
